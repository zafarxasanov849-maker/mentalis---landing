# Mentalis — landing

Milliy Sertifikat (MS) imtihoniga tayyorgarlik platformasining landing sahifasi.

## Deploy

Vercel'ga to'g'ridan-to'g'ri ulanadi — build step yo'q, bitta static `index.html`.

- Vercel'da repo'ni import qiling
- Framework: **Other** (yoki "No Framework")
- Build Command: **bo'sh qoldiring**
- Output Directory: **bo'sh qoldiring** (yoki `.`)
- Deploy

Keyin custom domain qo'shing (mentalis.uz yoki mentali.uz).

## Lokal ko'rish

Oddiygina `index.html`'ni brauzerda oching, yoki:

```bash
npx serve .
```
